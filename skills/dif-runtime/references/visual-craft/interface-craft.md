# Interface Craft

Use for UI creation and visual review after project context and Design System evidence are known.

## Context before aesthetics
Ground visual decisions in product subject, audience, primary task, content and existing visual language.

## Intentionality
Every meaningful visual choice must be traceable to at least one of:
- official Design System;
- product context;
- information hierarchy;
- interaction requirement;
- accessibility requirement.

Reject unexplained template-like patterns.

## Hierarchy
Use typography, spacing, alignment, density, contrast and composition to encode hierarchy. Decorative devices such as borders, labels, dividers, numbering and elevation must communicate structure or state.

## Typography
Preserve official typography. When typography is not constrained, define roles intentionally and optimize readability, hierarchy and line length. Avoid typographic decoration without informational purpose.

## Restraint
Prefer one clear visual emphasis over multiple competing accents. Remove decoration that does not support comprehension, hierarchy, state or brand intent.

## Content
Interface copy is functional content. Prefer clear user language, consistent action names, active voice and explicit recovery guidance for errors.

## Self-review
Before finalizing:
1. compare the result with the brief and source of truth;
2. identify generic or unexplained decisions;
3. remove unnecessary decoration;
4. verify hierarchy, readability, responsive behavior, focus visibility and reduced-motion requirements.
