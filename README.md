# Design Intelligence Framework (DIF)

Portable, versioned Design Intelligence Runtime for Codex and compatible environments.

## Use

1. Add organization-specific context in `workspace/WORKSPACE.md`, based on `workspace/WORKSPACE.example.md`.
2. Start the Runtime from `skills/dif-runtime/SKILL.md`.
3. Keep the Workspace private; the Runtime and its modules remain portable.

## Structure

- `skills/dif-runtime/`: runtime, discovery protocol, and task modules.
- `workspace/`: isolated organizational context.
