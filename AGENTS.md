# Design Intelligence Framework

- Use `skills/dif-runtime/SKILL.md` as the runtime entry point.
- Resolve intent through the Decision Tree and load only modules required by the task.
- Consult `workspace/WORKSPACE.md` only when organizational context is required.
- Discover Design Systems and component libraries from project evidence.
- Never invent organizational context, business rules, tokens, components, or Design System rules.
- Never transfer information between Workspaces.
- Preserve human approval for structural Design System changes.
- Validate results before completion.
